# structshift

R-пакет для расчёта **показателей структурных сдвигов и различий**:
интегрального коэффициента К. Гатева, индекса В. М. Рябцева (со шкалой
оценки), коэффициентов Л. С. Казинца, индекса различия и индекса А. Салаи.

Пакет задуман как учебный: он печатает полную расчётную таблицу (доли,
разности, квадраты), так что результат можно сверить с ручным расчётом.

## Установка

```r
install.packages("remotes")
remotes::install_github("astrageek/structshift")
```

## Быстрый старт

```r
library(structshift)

# Пример из учебника Гатевых (табл. 9.1): экспорт фирмы «Н» по группам стран
struct_shift(export_firm_n)
```

## Отдельные показатели

```r
base   <- c(ОЭСР = 0.30, ЦВЕ = 0.40, Арабские = 0.20, Другие = 0.10)
actual <- c(ОЭСР = 0.60, ЦВЕ = 0.20, Арабские = 0.15, Другие = 0.05)

gatev_index(base, actual)                     # 0.4315
ryabtsev_index(base, actual, interpret = TRUE) # 0.3204 + оценка по шкале
kazinets(base, actual)                        # четыре коэффициента Казинца
szalai_index(base, actual)                    # 0.2974
ryabtsev_scale()                              # шкала Рябцева целиком
```

## Формат данных

Можно передавать доли, проценты или абсолютные значения: всё
пересчитывается в доли автоматически.

* Два вектора: `gatev_index(c(10, 20, 70), c(20, 20, 60))`.
* Именованные векторы: элементы сопоставляются по названиям, порядок не важен.
* Таблица с колонками `element` / `base` / `actual`
  (понимаются и русские названия: `элемент`/`статья`, `базис`/`план`,
  `отчёт`/`факт`) или просто таблица с одной текстовой и двумя
  числовыми колонками:

```r
df <- data.frame(статья = c("Материалы", "Труд", "Прочие"),
                 базис  = c(500, 300, 200),
                 отчёт  = c(650, 280, 170))
struct_shift(df)
```

## Несколько структур

`shift_matrix()` сравнивает каждую структуру с каждой (периоды, регионы,
предприятия), а при `chain = TRUE` считает цепные сдвиги между соседними
периодами:

```r
# Структура себестоимости электроэнергии трёх ТЭЦ, 2008 и 2018 гг.
shift_matrix(tec_costs, index = "ryabtsev")
```

## Формулы

d₀, d₁ — доли элемента в базисной и отчётной структуре, k — число элементов.

| Показатель | Формула | Границы | Источник |
|---|---|---|---|
| Индекс различия | I<sub>S</sub> = Σ\|d₁ − d₀\| | 0–2 | Гатевы, ф. 9.3 |
| Нормированный индекс различия | I\*<sub>S</sub> = ½ Σ\|d₁ − d₀\| | 0–1 | Гатевы, ф. 9.4 |
| Линейный коэф. абсолютных сдвигов | Σ\|d₁ − d₀\| / k | — | Казинец; Гатевы, ф. 9.6 |
| Линейный коэф. относительных сдвигов | Σ\|d₁/d₀ − 1\|·d₀ | 0–2 | Казинец; Гатевы, ф. 9.7 |
| Квадратический коэф. абсолютных сдвигов | √(Σ(d₁ − d₀)² / k) | — | Казинец; Гатевы, ф. 9.8 |
| Квадратический коэф. относительных сдвигов | √(Σ(d₁/d₀ − 1)²·d₀) | — | Казинец; Гатевы, ф. 9.9 |
| Нормированный квадратический коэф. | σ\* = √(Σ(d₁ − d₀)² / 2) | 0–1 | Гатевы, ф. 9.10 |
| **Интегральный коэф. Гатева** | K<sub>S</sub> = √(Σ(d₁ − d₀)² / (Σd₀² + Σd₁²)) | 0–1 | Гатевы, ф. 9.12 |
| **Индекс Рябцева** | I<sub>R</sub> = √(Σ(d₁ − d₀)² / Σ(d₁ + d₀)²) | 0–1 | Афанасьев, ф. 9 |
| Индекс Салаи | I<sub>Sz</sub> = √(Σ((d₁ − d₀)/(d₁ + d₀))² / k) | 0–1 | Афанасьев, ф. 8 |

Для сравнения структур в пространстве (регионы, предприятия) коэффициент
Гатева называется интегральным коэффициентом структурных **различий**
K<sub>D</sub> (Гатевы, ф. 9.14). Вызовите `struct_shift(..., type = "difference")`.

### Шкала Рябцева

| I<sub>R</sub> | Оценка |
|---|---|
| 0,000–0,030 | тождественность структур |
| 0,031–0,070 | весьма низкий уровень различия |
| 0,071–0,150 | низкий уровень различия |
| 0,151–0,300 | существенный уровень различия |
| 0,301–0,500 | значительный уровень различия |
| 0,501–0,700 | весьма значительный уровень различия |
| 0,701–0,900 | противоположный тип структур |
| 0,901 и выше | полная противоположность структур |

Шкала есть только у индекса Рябцева. К коэффициенту Гатева и другим
показателям её применять некорректно.

## О чём помнить

* Все показатели зависят от **числа элементов** структуры. Сравнивать
  можно только структуры с одинаковым числом элементов (Гатевы, § 9.3.3).
* Коэффициент Гатева учитывает не только разности долей, но и их
  величину: сдвиг 20 % → 10 % весит больше, чем 90 % → 80 %.
* Квадратический коэффициент относительных сдвигов не определён, если
  базисная доля какого-либо элемента равна нулю. Индекс Салаи не определён,
  если элемент имеет нулевую долю в обеих структурах.
